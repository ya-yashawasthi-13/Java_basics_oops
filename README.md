# Java Basics & OOPs

Welcome to the **Java Basics & OOPs** repository! This project is dedicated to learning, practicing, and demonstrating fundamental Java programming concepts and core Object-Oriented Programming (OOP) principles.

## 📚 Topics Covered

### 1. Java Fundamentals
* Variables, Data Types, and Operators
* Control Flow Statements (if-else, switch, for/while loops)
* Methods and Variable Scope
* Arrays and Strings

### 2. Object-Oriented Programming (OOP)
* **Classes & Objects:** Creating blueprints and instantiating objects.
* **Encapsulation:** Protecting data using access modifiers and getter/setter methods.
* **Inheritance:** Promoting code reusability using the `extends` keyword.
* **Polymorphism:** Implementing method overloading (compile-time) and overriding (run-time).
* **Abstraction:** Hiding complex implementation details using abstract classes and interfaces.

### 3. Advanced Basics
* Exception Handling (`try-catch-finally`, custom exceptions)
* Basic Collections (ArrayList, HashMap)

## 🛠️ Prerequisites
* **Java Development Kit (JDK):** Version 8 or higher.
* **IDE/Text Editor:** IntelliJ IDEA, Eclipse, VS Code, or any standard text editor.
